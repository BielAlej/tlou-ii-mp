v1.03 - Patch Notes

New Features and Fixes

  • You can mark an enemy for your team if you aim at them and press the flashlight toggle keybind. On default controls that's T on keyboard or R3 on controller
  • Players are now based on the NPC class. As a result, there should be less crashes
  • Animation sync has been replaced with an entirely new system, almost identical to what Naughty Dog uses in Uncharted 4 Multiplayer and Factions. Previously we were using input based animation sync which had many inconsistencies. So we have 1:1 anim sync now. As a result of moving away from input based anim sync, this should get rid of crashes that stemmed from the input system
  • You can now heal, you are given 1 medkit on spawn
  • Spectate after death
  • Team mates show on radar
  • Voice lines now play when you start a match
  • Kill feed added
  • Listen mode now shows enemies like it would in SP rather than an outline
  • Shotguns fixed

Weapon Balancing

Most weapon stats have been adjusted to try and match the TTK, clip size and handling feeling of the original Factions.

Since TLOU2 is originally a Single Player game, some of the base damage values and multipliers were unusually high (e.g. the Bolt Rifle had a Base Damage of 80 with a x30 headshot multiplier).

We're open to feedback and actively working on improving the viability of all weapons!
